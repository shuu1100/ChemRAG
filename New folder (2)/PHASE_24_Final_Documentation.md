# Phase 24 — Final Documentation

## Goal
Produce complete engineering documentation.

## Prompt 24.1 — Developer Documentation
Document architecture, installation, environment variables, database, API, ingestion, parsing, OCSR, chemical normalization, embeddings, retrieval, reranking, agents, safety, frontend, evaluation, deployment, and troubleshooting.

## Prompt 24.2 — Architecture Diagrams
Generate Mermaid diagrams for system architecture, ingestion, retrieval, agent orchestration, database schema, citation flow, safety flow, and deployment.

## Prompt 24.3 — API Documentation
Generate complete OpenAPI documentation with purpose, authentication, request, response, errors, examples, and rate limits for every endpoint.

## Exit Criteria
- A new developer can install and understand the project from documentation alone.
