# Phase 14 — Frontend

## Goal
Build the React/TypeScript research interface.

## Prompt 14.1 — Application Shell
Create Dashboard, Documents, Document Viewer, Search, Chat, Chemical Explorer, Experiments, Jobs, Evaluation, and Settings pages. Use strict TypeScript, responsive layout, reusable components, and accessible UI.

## Prompt 14.2 — Document Management
Implement upload, drag/drop, progress, processing status, metadata, classification, errors, retry, archive/delete, search, and filters.

## Prompt 14.3 — ChemRAG Chat
Create a scientific chat interface supporting streaming responses, agent status, retrieval status, chemistry validation status, citations, confidence, source cards, tables, equations, and chemical structures.

## Prompt 14.4 — Agent Trace
Show safe operational status such as Planner, Retriever, Reranker, Chemistry Validator, Analytics, Safety, and Aggregator. Do not expose hidden chain-of-thought.

## Prompt 14.5 — PDF Evidence Viewer
Integrate PDF.js with page navigation, zoom, citation highlights, source sidebar, and bidirectional answer/source navigation.

## Exit Criteria
- Frontend connects to backend.
- Upload and chat flows work.
- Citation navigation works.
